# Cubism 狐狸分层素材导入要求

依据 [官方 PSD 导入说明](https://docs.live2d.com/en/cubism-editor-manual/reimport-psd/)：

- 使用 RGB、sRGB，部件图层名称唯一。
- 每个可变形部件的线条和颜色合为一个图层，应用图层蒙版。
- 清除透明区域内的残留像素，避免自动网格将杂点识别为部件。
- 保留可编辑的素材 PSD，另存用于导入的 PSD。
- 在 Cubism 中实际检查导入颜色、图层顺序、网格与遮挡。未经导入检查不能认定兼容。
